# MoonPDF 一页项目说明

**项目**：MoonPDF：MoonBit 原生 PDF 页面渲染引擎  
**方向**：文档处理 / 图形与渲染基础设施  
**仓库**：https://github.com/Yjh4899/moonpdf  
**发布**：https://mooncakes.io/docs/Yjh4899/moonpdf  
**版本**：0.44.0（Apache-2.0）

## 问题

MoonBit 已经能解析和生成 PDF，但还不能把一页画成像素。做缩略图、OCR 前置、文档预览或排版回归时，仍要依赖 PDF.js、JavaScript VM 或外部 `pdftoppm`。

MoonPDF 补的是这一层：输入 PDF，解释内容流，绘制路径、图像、字体、透明度和颜色，输出 PNG 或 SVG。纯 MoonBit 实现，可编译到 native 和 wasm，不依赖 FFI 渲染库。

## 已完成

- 文件结构：xref 表/流、object stream、混合 `/XRefStm`、`/Prev` 增量更新；
- 过滤器：Flate、ASCIIHex、ASCII85、RunLength、LZW；
- 页面树、资源继承、`/Rotate`、`/CropBox`；
- 路径填充/描边、裁剪、RGB/灰度/CMYK；
- Form XObject、图像 XObject、内联图像、`/SMask`；
- 嵌入 TrueType、CFF、Type1，Type0/CIDFontType2、CID-keyed CFF 和 CJK CMap；
- 文本状态、字距、标准 14 字体度量；
- 透明组、soft mask、blend mode（含 Hue/Saturation/Color/Luminosity）；
- shading、tiling/shading pattern、annotation appearance、optional content；
- PNG 输出，以及支持路径/图像/裁剪/嵌入字体文本的矢量 SVG。

## 验证

- 77 个单元/集成测试，全部通过；
- 39 个 fixture：全部可渲染，34 个在 0.90 像素容差内；
- 13 个真实公共 PDF：全部可渲染，5 个在容差内，0 崩溃 / 0 超时；
- 120 个 malformed case fuzz：0 崩溃 / 0 超时；
- CI 覆盖 wasm-gc 与 native 测试、fixture 渲染和像素探针；
- 干净 clone 构建、测试、CLI 出图通过。

## 边界

真实 PDF 的剩余差异集中在字体 hinting、CFF 子集和图像颜色细节。IRS 1040/W-9 约 82%，blendmode 约 87%，GPT-4 约 88%。这些差距记录在 `docs/corpus-report-real.md` 和 `docs/acceptance.md`，没有写成“已支持”。

加密 PDF、完整 ICC 色彩管理和浏览器 wasm 封装尚未完成，已列入后续计划。

## 合规

项目代码 Apache-2.0；内置 OpenSans 子集为 SIL OFL 1.1；PDF 规范是主要实现依据；MuPDF、PDFium、Poppler 只用于行为对照，没有复制代码。
